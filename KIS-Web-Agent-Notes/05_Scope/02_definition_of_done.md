## 1. 🔴 요구사항 완료 기준 (제출 필수)

### REQ-01 :: 주제

- [ ] 프로젝트 2 기획서를 기반으로 했음을 문서에 명시했습니다.
- [ ] **웹이기 때문에 가능해진 것 5가지**를 문서에 적었습니다. ([[../01_Baseline/01_project_statement|한 문장]] 4절)
- [ ] **무엇을 뺐는지와 그 이유**를 제출 문서에 적었습니다. ([[../07_Submit/02_scope_reduction|범위 축소 설명서]])

### REQ-02 :: AI 기능

- [ ] AI-1: 계좌 숫자를 넣으면 **매번 다른 해석 문장**이 나옵니다.
- [ ] AI-1: 종목 시세를 넣으면 해석 문장이 나옵니다.
- [ ] AI-2: 근거 목록을 넣으면 회고 코멘트가 나옵니다.
- [ ] 🔴 **미리 만들어 둔 응답이 아닙니다.** 데이터가 바뀌면 결과가 바뀝니다.
- [ ] AI 응답 30건을 검사해 **매수·매도 권유 표현이 0건**입니다.
- [ ] AI 응답 30건에 **목표가·수익률 예측이 0건**입니다.

> 검사 방법: `event_logs`에서 AI 호출 이벤트를 세고, 화면에서 실제 응답 30건을 눈으로 읽습니다.

### REQ-03 :: 데이터 저장

- [ ] Supabase에 테이블이 6개 있습니다.
- [ ] 🔴 **주문을 넣고 브라우저를 완전히 종료한 뒤 다시 열어도 회고 화면에 그 주문이 있습니다.**
- [ ] 근거(`rationales`)가 주문(`orders`)과 연결되어 저장됩니다.
- [ ] 주문이 거부되어도 근거는 남아 있습니다.

### REQ-04 :: 배포

- [ ] 접속 가능한 Vercel URL이 있습니다.
- [ ] 🔴 **시크릿 창에서 열어 화면 3개가 모두 보입니다.**
- [ ] 🔴 **다른 기기(휴대폰)에서 열어 화면 3개가 모두 보입니다.**
- [ ] 🔴 **시크릿 창·휴대폰에서 Google 로그인이 실제로 완료되고 돌아옵니다.** (리디렉션 URL이 배포 도메인 기준으로 맞게 설정되어 있어야 함)
- [ ] 로컬에서만 있는 환경변수가 없습니다. (Vercel 대시보드와 대조)
- [ ] 첫 로딩이 5초 안에 끝납니다.

### REQ-05 :: 최소한의 사용성

- [ ] 첫 화면에 **이 서비스가 무엇을 하는지** 한 문장이 있습니다.
- [ ] 첫 화면에 **무엇을 먼저 눌러야 하는지** 버튼 3개가 있습니다.
- [ ] 🔴 **Gemini API 키를 일부러 틀리게 해도 화면이 깨지지 않습니다.** 숫자는 그대로 보입니다.
- [ ] 🔴 **수량을 비운 채 주문하면** 아무 일도 일어나지 않고 안내 문구만 나옵니다.
- [ ] 🔴 **근거를 고르지 않으면 주문 버튼이 눌리지 않습니다.**
- [ ] 검색 결과가 0건일 때 지원 종목 예시가 함께 나옵니다.
- [ ] 데이터가 하나도 없는 상태(회고 화면 첫 방문)에서 안내 문구가 나옵니다.
- [ ] 로딩 중임을 알 수 있습니다. (빈 화면이 아님)

## 2. 🔴 안전 기준 (주문 관련)

**이 항목들이 지켜지지 않으면 기능이 아무리 많아도 완료가 아닙니다.**

- [ ] 🔴 **근거를 고르지 않은 주문이 KIS에 도달하지 않습니다.**
  - 검증: `orders`에 `rationales`가 없는 `submitted` 행이 0건
- [ ] 🔴 **가상 예산을 초과하면 KIS가 호출되지 않습니다.**
  - 검증: 한도를 초과하는 수량으로 시도 후 `orders` 행이 늘지 않음 + `order_rejected_budget_exceeded` 기록됨
- [ ] 🔴 **장 마감 시간에 주문하면 접수되지 않습니다.**
  - 검증: Day 3(토)에 실제로 시도. 휴장일이므로 그대로 검증됨
- [ ] 실제 계좌 예수금을 초과하는 주문이 차단됩니다.
- [ ] 같은 주문을 연타해도 1건만 들어갑니다.
- [ ] 클라이언트에서 `qty`를 조작해도 서버가 시세를 재조회해 금액을 다시 계산합니다.
- [ ] 계정 A로 주문해도 계정 B의 가상 예산은 줄지 않습니다. (다른 Google 계정으로 로그인해 확인)
- [ ] 로그인하지 않고 [주문하기]를 누르면 KIS가 호출되지 않고 Google 로그인 버튼이 뜹니다.

## 3. 🔴 자격증명·개인정보 기준

- [ ] `NEXT_PUBLIC_`이 붙은 환경변수가 **Supabase URL과 anon key 2개뿐**입니다.
- [ ] 브라우저 개발자 도구 → Sources에서 `KIS_APP_KEY`를 검색해 **0건**입니다.
- [ ] 브라우저 Network 탭에 KIS·Gemini 도메인 호출이 **0건**입니다.
- [ ] 화면 어디에도 계좌번호가 표시되지 않습니다.
- [ ] `select payload from event_logs limit 50`에 토큰·계좌번호가 없습니다.
- [ ] `.env.local`이 `.gitignore`에 있고, GitHub 리포지토리에 올라가지 않았습니다.
- [ ] 🔴 **시연 영상과 발표자료 스크린샷에 계좌번호가 보이지 않습니다.**

> 🔴 마지막 항목은 녹화 후에 반드시 재생해서 확인합니다. 화면 구석에 잠깐 보이는 경우가 있습니다.

## 4. 화면별 완료 기준

### `/` 계좌 대시보드

- [ ] 예수금·총평가금액·평가손익이 표시됩니다.
- [ ] 보유 종목이 있으면 목록이 표시됩니다.
- [ ] 보유 종목이 0개여도 화면이 깨지지 않습니다.
- [ ] [이게 무슨 뜻인가요?] 버튼을 누르면 AI 해석이 나옵니다.
- [ ] 화면 진입만으로는 AI가 호출되지 않습니다.

### `/trade` 종목 조회와 주문

- [ ] `삼성`으로 검색하면 후보가 나옵니다.
- [ ] `삼성전자` 검색 시 `삼성전자우`가 함께 나오고 **자동으로 하나를 고르지 않습니다.**
- [ ] 없는 종목을 검색하면 예시와 함께 안내가 나옵니다.
- [ ] 종목을 고르면 현재가·등락률이 표시됩니다.
- [ ] 수량을 입력하면 예상금액이 계산됩니다.
- [ ] 근거 6개가 라디오 버튼으로 표시됩니다.
- [ ] 메모를 비워도 주문이 진행됩니다.
- [ ] 확인 모달에 "이 주문 후 남는 예산 OOO원"이 표시됩니다.
- [ ] 주문 성공 시 주문번호와 회고 화면 링크가 나옵니다.
- [ ] 가상 예산을 초과하는 수량을 입력하면 주문 전에 차단되고 남은 한도가 안내됩니다.

### `/journal` 근거 회고

- [ ] 주문 목록이 최신순으로 나옵니다.
- [ ] 🔴 **다른 계정으로 로그인하면 이전 계정의 주문은 보이지 않습니다.**
- [ ] 로그인하지 않아도 (내가 아닌) 전체 서비스 소개와 빈 상태 화면은 볼 수 있습니다.
- [ ] 각 행에 종목·수량·주문일·당시가·근거 유형·메모가 있습니다.
- [ ] 보유 종목의 현재가가 당시가와 함께 표시됩니다.
- [ ] 상단에 총 주문 수와 근거 기록률이 표시됩니다.
- [ ] [내 근거 되돌아보기]를 누르면 AI 코멘트가 나옵니다.
- [ ] 🔴 **KIS를 끊어도(환경변수를 틀리게 해도) 목록과 집계는 보입니다.**
- [ ] 데이터가 0건일 때 "아직 기록이 없습니다 + [첫 주문 해보기]"가 나옵니다.
