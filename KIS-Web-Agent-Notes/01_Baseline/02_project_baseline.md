## 2. 프로젝트 목적

사용자가 자신의 매매 판단 근거를 **기록하고, 모아 보고, 설명할 수 있게** 합니다.

수익을 내게 하는 것이 목적이 아닙니다. 종목을 추천하는 것도 목적이 아닙니다.

---

## 3. 문제 정의

```
모의투자를 시작한 초보 투자자는 매수 시점에는 나름의 이유가 있지만,
그 이유가 어디에도 남지 않아 며칠 뒤에는 자신이 왜 샀는지 설명하지 못합니다.
설명하지 못하면 그 판단이 옳았는지 틀렸는지도 배울 수 없습니다.
```

증거 아닌 것과 증거인 것을 구분합니다.

| 구분 | 내용 |
|---|---|
| 사실 | KIS 앱과 증권사 앱은 주문 내역을 보여주지만 **주문 사유 필드가 없습니다** |
| 해석 | 사유가 없으므로 회고가 감(感)에 의존하게 됩니다 |
| 가정 | 사유를 남기면 회고가 가능해집니다 → **이 프로젝트가 검증하려는 가정** |

### 5.3 🔴 서버리스 제약

Vercel의 Route Handler는 **요청마다 새로 뜨고 메모리를 공유하지 않습니다.** 프로젝트 2에서는 n8n이 계속 떠 있어서 성립했던 것이 여기서는 성립하지 않습니다.

| 항목 | n8n | Vercel |
|---|---|---|
| KIS 접근토큰 보관 | 워크플로우가 관리 | 🔴 **Supabase 테이블에 캐시 필수** |
| 호출 IP | 고정 (내 서버) | 🔴 **매번 다름** |
| 실행 시간 제한 | 없음 | Hobby 기준 10초 |
| 스케줄러 | 있음 | 없음 (Cron 별도) |

이 표가 [[../04_Architecture/02_architecture|아키텍처]]와 [[../03_Data_Event/01_data_structure|데이터 구조]]의 주요 설계 근거입니다.

## 6. 🔴 대안 시나리오 — KIS 연결이 막힐 경우

Day 1의 첫 작업은 **Vercel 배포본에서 KIS 토큰 발급이 되는지 확인**하는 것입니다. 여기서 막히면 4일이 통째로 위험합니다. 그래서 판단 시점과 대안을 미리 정합니다.

```
판단 시점: 8/7(금) 12:00
조건:     Vercel 배포 URL에서 KIS 잔고 조회가 성공하지 못했다
```

### 대안 A — KIS를 모의 데이터로 대체

| 유지 | 대체 |
|---|---|
| 화면 3개, 근거 입력 강제, 회고 화면, AI 3종, Supabase, Vercel | 계좌·시세를 **고정 시드 데이터**로 대체 |

요구사항 REQ-01~05는 **전부 그대로 만족합니다.** KIS는 요청서 요구사항이 아니기 때문입니다. 발표에서 "외부 API 연동은 배포 환경 제약으로 시드 데이터로 대체했다"고 명시합니다.

### 대안 B — KIS 호출만 별도 경유

n8n 워크플로우를 웹훅으로 열어 두고 Next.js가 그것을 호출합니다. IP가 고정되므로 문제가 해소됩니다.

> 대안 B는 **대안 A보다 뒤에 둡니다.** 구성 요소가 하나 늘고, 발표 시점에 n8n이 떠 있어야 하는 의존이 생기기 때문입니다.

**결정 원칙: 8/7 12:00에 판단하고, 그 이후에는 되돌리지 않습니다.**

## 9. 개인정보·자격증명 원칙

| 항목 | 취급 |
|---|---|
| KIS 앱키·시크릿 | **서버 전용 환경변수.** `NEXT_PUBLIC_` 접두사 절대 금지 |
| KIS 계좌번호 | 서버 전용 환경변수. 화면·로그·문서·발표자료에 노출 금지 |
| Gemini API 키 | 서버 전용. Route Handler에서만 호출 |
| Supabase service role key | 사용하지 않음. anon key + RLS로 처리 |
| Google OAuth 클라이언트 시크릿 | Supabase 대시보드에만 등록. 앱 코드·환경변수에 두지 않음 |
| 로그인 사용자 UUID (`auth.users.id`) | Supabase Auth가 발급·관리. 이메일 등 추가 개인정보는 별도로 수집하지 않음 ([[../02_Domain/02_user_roles\|사용자 역할]]) |

> 🔴 **`NEXT_PUBLIC_` 접두사가 붙은 값은 브라우저 번들에 그대로 들어갑니다.** 배포 전에 환경변수 이름을 한 번 확인합니다. ([[../05_Scope/02_definition_of_done|완료 기준]] 보안 항목)
